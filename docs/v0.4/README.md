# v0.4 母图—子图—交叉导航试验版

v0.4 保留根目录的 v0.3 页面，在 `atlas/` 中增加一个独立的教学图谱入口：

- `atlas/index.html#overview`：机制总览母图，显示电离辐射、DNA/氧化应激、MuSC、FAP、免疫、血管/内皮、ECM 和组织结局的粗粒度关系。
- `atlas/index.html#musc-fap-ecm`：现有 MuSC–FAP–ECM 核心子图，沿用 v0.3 的逐箭头证据数据。
- `atlas/index.html#dna-redox`：DNA 损伤与氧化应激子图，区分直接肌肉细胞证据、经典条件通路和候选修复窗口。

母图到子图的虚线/点划线标记为 **N级·机制导航**，不属于生物学因果箭头。每条生物学箭头仍使用 A/B/C 证据层：A级为直接辐射模型，B级为条件性参照，C级为推断、摘要级或动物候选干预。

## 构建与验证

```sh
node build-v04.mjs
node verify-v04.mjs
```

`validation.json` 记录了数据约束、母图/子图跳转、返回、共享节点、播放/暂停/重播、筛选、中英文切换、减少动画和 390px、320px、横屏及桌面视口检查。截图与验证文件保存在本目录。

## 明确保留的科学边界

- FAP 分泌组对成肌分化/融合的抑制保留为功能性结果，未指定具体抑制因子。
- p-SMAD3 仅作为早期辐射响应呈现，56天恢复，不画成晚期持续激活。
- WNT7A–FZD7–VANGL2/PCP 与经典 Wnt/β-catenin 分开。
- Pax3 仅指稀有储备 MuSC 亚群。
- SB-505124 和 SFN 是动物候选干预，不表示人体疗效。
- ROS→DNA、DNA修复失败→长期MuSC耗竭、NRF2→SMAD3直接抑制和 FAP来源TGF-β1→MuSC抑制列入不绘制清单。
- 动画仅规定讲解顺序，不是定量动力学、风险或临床疗效预测。
